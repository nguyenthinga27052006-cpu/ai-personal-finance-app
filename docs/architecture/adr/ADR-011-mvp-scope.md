# ADR-011: MVP V1 Scope

- **Status:** Accepted

## Context
The blueprints describe a broad platform, but reliable financial core must precede advanced intelligence.

## Decision
Freeze MVP V1 to authentication, user basics, accounts, categories, income/expense/transfer/refund/split transactions, dashboard, budget, basic analytics and basic budget notifications. Prepare only an AI Gateway abstraction; advanced AI is disabled.

## Alternatives
Build the entire blueprint at once, prioritize AI assistant, include bank integrations early.

## Consequences
A smaller testable release with trustworthy data; goals, recurring transactions, OCR, insights, recommendations and advanced AI remain prioritized follow-up work.
